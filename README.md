# 🚀 Selected Projects

### 🧠 DistGPU

Distributed platform for running **PyTorch training on remote GPU workers**.

Supports distributed training workflows including **DDP and multi-node FSDP**, job scheduling, WebSocket communication, browser log streaming and a native C++ worker.

**Python · PyTorch · FastAPI · WebSockets · CUDA · C++ · Distributed Systems**

---

### 🎬 Video Object Replacer

AI-powered video object replacement pipeline.

The project explores object detection, segmentation and generative replacement using **Grounding DINO, SAM2, SDXL/Inpainting and modern generative APIs**.

**Python · Computer Vision · Transformers · SAM2 · Generative AI**

---

### 🤖 Media Helper

A full-stack media platform built around a Telegram bot and web Mini App.

Supports media downloading, music recognition, playlists, a Spotify-style player, background workers and PostgreSQL-backed infrastructure.

**Python · PostgreSQL · Telegram · JavaScript · Mini App**

---

### ⚡ Remote Desk

A C++ remote management system consisting of a **relay server, agent and administrator client**.

Includes a custom communication protocol, remote command execution, screenshots and connection management.

**C++17 · Networking · Systems Programming**

---

### ⚽ Kickoff

Full-stack football application with a backend, Telegram bot, frontend and containerized infrastructure.

**Python · FastAPI · PostgreSQL · Vue/TypeScript · Docker**

---

### 🧪 ML from Scratch

Educational/research-oriented implementations of classical machine learning algorithms.

Includes:

* Random Forest

* PCA

**Python · NumPy · Machine Learning**

**C · Computer Architecture · Emulation**
